# OpenFox Web 端使用指南

> OpenFox 的 Web 界面：在浏览器里配置智能体、与智能体多会话聊天。

## 前置要求

- Python 3.13+（后端）
- Node.js 18+ 与 npm（前端，首次使用需要）
- 已配置好 `config.yaml`（模型列表）

## 启动步骤

### 1. 启动后端

```powershell
# PowerShell
openfox-server --host 127.0.0.1 --port 8000
```

```bash
# Git Bash
openfox-server --host 127.0.0.1 --port 8000
```

### 2. 安装前端依赖（首次）

```powershell
cd web
npm install
```

### 3. 启动前端

```powershell
cd web
npm run dev
```

浏览器打开 **http://localhost:5173**。

> Vite 开发服务器会把 `/v1/*` 请求代理到后端 `http://127.0.0.1:8000`，前后端无需跨域配置。

## 页面功能

### 智能体管理（`/agents`）

管理智能体配置：

- **新建智能体**：点击顶部"新建智能体"按钮
  - **名称**：显示名（必填）
  - **ID**：唯一标识（必填，创建后不可改）
  - **描述**：一句话说明用途
  - **模型**：绑定模型（留空 = 使用全局默认模型）
  - **系统提示词**：智能体专属指令，会附加到系统提示词
  - **工具**：勾选启用的工具（不勾 = 全部启用）
  - **技能**：勾选启用的技能（不勾 = 全部启用）
  - **温度**：采样温度（0~2，默认 0.7）
  - **最大步数**：单轮最多工具调用次数（默认 20）
- **编辑**：修改已有智能体配置
- **测试**：验证智能体绑定的模型是否可用
- **删除**：二次确认后删除

> 智能体配置保存到 `config.yaml` 的 `agents` 段（保留 models/storage 等其他段），重启服务后依然存在。

### 聊天工作台（`/chat`）

与智能体对话：

1. **选择智能体**：左侧下拉框选择要对话的智能体
2. **新建会话**：点击"新建"创建会话，会话绑定当前智能体
3. **发送消息**：底部输入框输入，Enter 发送，Shift+Enter 换行
4. **查看工具调用**：智能体调用工具时，回复下方展示"工具调用轨迹"面板（工具名、参数、结果）

功能说明：

- 会话按智能体绑定：切换到另一智能体时，会话列表展示该智能体的会话
- 多会话隔离：每个会话独立保存消息历史
- 发送后显示"停止"按钮（MVP 为非流式，整段返回后渲染）
- 助手回复支持 Markdown 渲染

## 生产部署（可选）

把前端构建产物交给后端托管，实现单端口访问：

```powershell
cd web
npm run build
```

构建产物在 `web/dist/`。将 `dist/` 目录内容复制到后端静态目录（后续版本支持 FastAPI 自动托管），或使用 Nginx 托管静态文件 + 反代 `/v1` 到后端。

## 常见问题

### 前端打不开 / 页面空白

- 确认后端已启动：访问 http://127.0.0.1:8000/healthz 应返回 `{"status":"ok",...}`
- 确认前端在 http://localhost:5173（Vite 默认端口）

### 下拉框没有智能体

- 需要先在"智能体管理"页创建一个智能体
- 或者确认 `config.yaml` 的 `agents` 段存在且格式正确

### 发消息报错 / 无回复

- 查看后端终端日志，确认模型 API key 已配置（`.env` 或环境变量）
- 用 `curl http://127.0.0.1:8000/v1/agents` 检查智能体是否存在

## API 速查

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/v1/agents` | 列出智能体 |
| POST | `/v1/agents` | 创建智能体 |
| PUT | `/v1/agents/{id}` | 更新智能体 |
| DELETE | `/v1/agents/{id}` | 删除智能体 |
| GET | `/v1/agents/{id}/test` | 测试模型连通性 |
| POST | `/v1/agent-chat` | 按智能体聊天 |
| GET | `/v1/sessions` | 列出会话 |
| POST | `/v1/sessions` | 创建会话 |
| GET | `/v1/sessions/{id}/messages` | 会话消息 |
| DELETE | `/v1/sessions/{id}` | 删除会话 |

# 联网搜索 (Web Search)

## 用途

当用户提出需要联网才能回答的问题时，通过必应（Bing）搜索引擎获取实时结果，并可进一步抓取网页全文获取详细信息。无需任何 API Key。

引擎优先级：必应中国（cn.bing.com，国内直连快）→ DuckDuckGo（备用，国内可能超时）。默认 auto 模式自动切换。

## 工作流

### 第一步：判断是否需要搜索

以下场景应主动搜索：
- 用户明确要求搜索（"搜一下"、"查一下"、"帮我查查"）
- 涉及实时信息（新闻、天气、股价、赛事比分、发布日期）
- 涉及你知识截止后的事件或更新
- 你对某个事实不确定，需要验证
- 用户问"最新"、"现在"、"最近"相关的内容

### 第二步：执行搜索

```bash
python skills/web-search/scripts/search.py --query "搜索关键词" --num 5
```

- `--query`：搜索关键词，建议用精炼的查询词（中英文均可）
- `--num`：结果数量，默认 5 条（最多建议 10 条）
- `--json`：加此参数输出 JSON 格式（适合程序化处理）
- `--engine`：指定引擎，auto（默认，先 Bing 后 DDG）/ bing / ddg

输出每条结果包含：标题、URL、摘要。

### 第三步：按需抓取网页全文

如果搜索结果的摘要信息不够，需要查看某个网页的完整内容：

```bash
python skills/web-search/scripts/search.py --fetch "https://example.com/article" --max-chars 5000
```

- `--fetch`：要抓取的网页 URL（从搜索结果中获取）
- `--max-chars`：最大提取字符数，默认 5000（避免返回过长内容浪费上下文）

输出包含：网页标题、正文文本（已去除导航栏/广告等噪声）。

### 第四步：整合回答

1. 阅读搜索结果摘要（和网页全文）
2. 用中文整理成简洁、有条理的回答
3. 在回答末尾附上参考来源链接（选取 1-3 个最相关的）
4. 如果搜索结果相互矛盾，指出差异让用户判断

## 使用示例

**示例 1：简单搜索**

用户问："最近 AI 领域有什么重大突破？"

```bash
python skills/web-search/scripts/search.py --query "AI 重大突破 2026" --num 5
```

阅读结果后用中文总结，附参考链接。

**示例 2：搜索 + 抓取详情**

用户问："Python 3.13 有什么新特性？"

先搜索：
```bash
python skills/web-search/scripts/search.py --query "Python 3.13 新特性" --num 5
```

发现一篇优质文章，抓取全文：
```bash
python skills/web-search/scripts/search.py --fetch "https://docs.python.org/3.13/whatsnew/" --max-chars 5000
```

基于全文内容整理回答。

**示例 3：验证事实**

用户问："NASA 的阿尔忒弥斯计划推迟到什么时候了？"

```bash
python skills/web-search/scripts/search.py --query "Artemis mission delay date 2026" --num 5
```

## 注意事项

1. **搜索关键词**建议精炼，避免过长句子。中文搜索用简短词组效果最好（如"人工智能 最新新闻"比"2026年8月有什么人工智能最新新闻"效果好）；技术类内容用英文搜索效果更好
2. **不要对同一个查询反复搜索**，如果第一次结果不理想，换关键词而不是重搜
3. **抓取网页全文**前先看摘要是否已经足够，避免不必要的抓取浪费上下文
4. **回答要标注信息来源**，让用户知道信息获取时间和大致来源
5. 如果搜索失败（网络问题），如实告诉用户，不要编造答案
6. **引擎说明**：默认 auto 模式优先使用必应中国（cn.bing.com），国内直连速度快；DuckDuckGo 作为备用引擎在国内可能超时。如需指定引擎可加 `--engine bing` 或 `--engine ddg`

# 运营商投诉信息抽取

## 目标

把一段自由书写的运营商投诉文本转成 4 个固定字段的结构化 JSON，便于填单、归档、统计。字段必须严格按下面的定义和顺序输出，这是本技能唯一要交付的东西。

| 字段 | 含义 | 缺失时 |
|---|---|---|
| 投诉人姓名 | 投诉人自称的名字（"投诉人：张三""我叫张三""本人张三"） | 空字符串 "" |
| 投诉人联系方式 | 手机号、座机、400/800 号码、微信号、QQ、邮箱等，多个用"；"连接 | 空字符串 "" |
| 投诉事由 | 发生了什么、为什么投诉：问题描述、起因、经过 | 空字符串 "" |
| 处理诉求 | 投诉人明确要求的处理结果：退费、赔偿、恢复、销户、转网、道歉、时限等 | 空字符串 "" |

## 抽取原则（先读这里）

1. **忠实原文，不做推断**。事由和诉求尽量贴近原文表达，保留关键实体：金额（100元）、日期/时长（上月、本月、一个月）、套餐名（58元畅享套餐）、号码、地点、次数（报了三次修）。不要概括性改写，不要脑补原文没有的信息（比如原文只说"乱扣费"，不要写成"扣了50元话费"）。
2. **事由 vs 诉求的分界**。事由 = 已经发生的问题；诉求 = 想要的结果。"宽带断网"是事由，"退还本月宽带费"是诉求。带"否则/不然"的威胁句式（"不然我就去工信部投诉"）是诉求的组成部分，要一并保留，因为它反映了投诉人的底线。
3. **缺失就填空字符串**，绝不编造。但称谓不算缺失：只出现"王先生/李女士"时，姓名字段原样保留该称谓。
4. **联系方式**：打码号码（138****5678）原样保留，不要尝试补全或"修正"；同一人多个联系方式（手机+微信）全部提取，用中文分号"；"连接。识别规则：`1[3-9]` 开头的 11 位手机号、`0` 开头带区号的座机、400/800 号码、`微信号/微信:`、`QQ:`、邮箱地址。
5. **多投诉人**：一段文本里若有多位投诉人、各自带着自己的身份信息和自己的投诉内容（联名投诉、多起独立投诉），每位投诉人输出一个对象，整体输出 JSON 数组；否则输出单个对象。注意区分：文本里提到其他人（客服、家人、被投诉的营业厅）不算多投诉人，只有"各自在投诉、各自有身份信息"才算。
6. **只输出 JSON**。不要输出解释、前后缀、Markdown 代码块，也不要输出"以下是抽取结果"之类的废话——下游程序会直接消费这个 JSON。除非用户明确要求其他格式（表格、自然语言等），按用户要求来。

## 输出格式

单条投诉（默认）：

```json
{
  "投诉人姓名": "王丽",
  "投诉人联系方式": "138****5678",
  "投诉事由": "办理58元畅享套餐，宣传每月30G流量，实际使用15G后即被限速，观看视频频繁卡顿，两次致电客服未解决",
  "处理诉求": "恢复网速，并补偿本月话费"
}
```

多投诉人（数组，每项一个投诉人）：

```json
[
  {"投诉人姓名": "张敏", "投诉人联系方式": "13812340001", "投诉事由": "流量包总是自动续费悄悄扣钱", "处理诉求": "退还多扣的费用并道歉"},
  {"投诉人姓名": "李强", "投诉人联系方式": "13912340002", "投诉事由": "办宽带时被莫名多收了100元安装费", "处理诉求": "退还多扣的费用并道歉"}
]
```

## 输入形式

- **单条文本**：用户直接粘贴一段投诉内容 → 按上面的格式输出 JSON。
- **批量文本**：用户给文件（txt 每行一条 / csv 含投诉文本列 / xlsx），逐条抽取 → 输出 JSON 数组，并按"批量转 CSV"一节生成 CSV 交付。
- **信息分散在会话里**：联系方式可能单独补一句（"电话是138xxx"），抽取时要结合整个会话上下文，只抽投诉相关字段，忽略无关闲聊。

## 批量转 CSV

批量时除了输出 JSON 数组，还要落盘生成 CSV（Excel 直接打开不乱码）：

1. 把 JSON 数组用 write_file 写到 `workspace/` 下，如 `workspace/complaint_result.json`（文件内容只含 JSON，不要包 Markdown 代码块，否则脚本解析失败）。
2. 执行：
   ```
   python skills/complaint-extract/scripts/json_to_csv.py workspace/complaint_result.json workspace/complaint_result.csv
   ```
   （run_shell 的 cwd 是项目根目录，脚本用相对项目根的路径调用。）
3. 告诉用户 CSV 保存路径，并把 JSON 数组一并输出在回复里。

xlsx 文件先用 python 读（`import pandas as pd; df = pd.read_excel(...)`，pandas/openpyxl 通常已安装；若报缺依赖，请用户另存为 csv），再逐条抽取。

## 示例

**示例 1（工单格式 + 打码电话）：**
输入：`投诉人：王丽，联系电话：138****5678。本人于上月办理中国移动58元畅享套餐，宣传每月30G流量，本月实际使用15G后即被限速，观看视频频繁卡顿。已两次致电客服反映均未解决。诉求：恢复网速，并补偿本月话费。`
输出：见上文"输出格式"第一例。

**示例 2（无姓名 + 威胁句式）：**
输入：`宽带从上周开始一直断网，报修三次没人来处理，客服电话也打不通。本人手机号13812345678，要求退还本月宽带费用，不然我就去工信部投诉你们！`
输出：
```json
{"投诉人姓名": "", "投诉人联系方式": "13812345678", "投诉事由": "宽带从上周开始一直断网，报修三次没人来处理，客服电话也打不通", "处理诉求": "退还本月宽带费用，不然我就去工信部投诉你们"}
```

**示例 3（称谓代替姓名 + 多联系方式）：**
输入：`王先生反映，宽带电视自安装以来经常卡顿黑屏，维修师傅上门三次没修好。手机13900001111，微信wang2024。强烈要求更换机顶盒并减免两个月收视费。`
输出：
```json
{"投诉人姓名": "王先生", "投诉人联系方式": "13900001111；微信wang2024", "投诉事由": "宽带电视自安装以来经常卡顿黑屏，维修师傅上门三次没修好", "处理诉求": "更换机顶盒并减免两个月收视费"}
```

**示例 4（多投诉人）：**
输入：`我和同事李强一起投诉：我（张敏，13812340001）的流量包总是自动续费悄悄扣钱，他（李强，13912340002）办宽带时被莫名多收了100元安装费。我们都要求运营商退还多扣的费用并道歉。`
输出：见上文"输出格式"第二例。
